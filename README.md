# AI Doctor with Vision and Voice

AI Doctor with Vision and Voice is a Python-based AI project exploring multimodal healthcare assistance through voice interaction and image-aware workflows.

## Overview

The project combines conversational AI, speech input/output, and image-related capabilities to demonstrate how an AI assistant can interact with users beyond text-only chat.

## Technology

- Python
- Groq
- SpeechRecognition
- PyAudio and Pydub
- gTTS
- ElevenLabs
- Gradio
- python-dotenv

## Purpose

This project is a practical exploration of voice-enabled and vision-aware AI assistants, with an emphasis on integrating multiple AI and audio technologies in one application.
